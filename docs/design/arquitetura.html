Mapa do Sangue

tráfego do usuário (HTTPS) chamada interna deploy
Cada linguagem no que faz melhor

Next.js (TypeScript) cuida das páginas e das regras que rodam no navegador, como o "Posso doar?". Go cuida dos dados: coleta, banco e API.

SEO de verdade

Uma página por estado e por hemocentro, gerada no servidor e renovada a cada 30 minutos (ISR), com sitemap e dados estruturados.

Nenhuma porta aberta

O Cloudflare recebe o tráfego e segura DDoS. A VPS só fala para fora pelo túnel, então a API não fica exposta na internet.

Testado nos três sistemas

Vitest no web, go test na API com Postgres instalado no runner e Playwright no e2e, em Linux, macOS e Windows, com cobertura no Codecov.
