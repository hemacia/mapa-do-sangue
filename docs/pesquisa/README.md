Levantamento feito em novembro de 2026, antes de começar a implementação, para saber se o projeto era viável e de onde viriam os dados.

- [relatorio-fontes-de-dados.md](relatorio-fontes-de-dados.md): relatório consolidado (cobertura por UF, fontes, regras de doação, arquitetura e roteiro)
- [notas/](notas/): notas de cada frente da pesquisa, com as fontes citadas
  - `estoques_norte_nordeste.md` e `estoques_centro_sul.md`: como cada hemocentro publica o estoque
  - `dados_nacionais_localizacao.md`: Anvisa Hemoprod, CNES, IBGE, DATASUS
  - `projetos_github.md`: projetos open source parecidos e o que dá para reaproveitar
  - `regras_doacao.md`: Portaria GM/MS nº 11.685/2026 (base das regras de negócio)
  - `produto_ux_stack.md`: referências de produto e escolhas técnicas

Os seletores e endpoints valem para a data da coleta e podem mudar sem aviso.
